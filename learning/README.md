.venv/# AutoTrust Python Learning

This folder is for learning Python through the AutoTrust project.

## Lesson 1: Python Basics

Run:

```powershell
python .\learning\lesson1.py
```

What it teaches:

- Dictionaries
- Adding a new key/value pair
- f-strings
- Functions
- `*args`

## Lesson 2: OOP Console App

Run:

```powershell
python .\learning\autotrust_oop_console.py
```

What it teaches:

- Classes
- Objects
- Methods
- `dataclass`
- `Enum`
- Type hints
- Console input
- Lists of objects
- Basic business logic
- Reading from a JSON file
- Writing to a JSON file
- File database pattern

The console app writes reports to:

```text
learning/autotrust_db.json
```

That JSON file is your temporary database for now. Later, the same idea can grow into SQLite, PostgreSQL, Firestore, or an API repository.
- File storage with JSON

When you create an inspection report, the app saves it into:

```text
learning/autotrust_db.json
```

That JSON file is your temporary "database" for now.

## C# to Python Mental Map

| C# | Python |
| --- | --- |
| `class Vehicle { }` | `class Vehicle:` |
| Properties | Attributes |
| Methods | Methods with `self` |
| `List<T>` | `list[T]` |
| `enum` | `Enum` |
| Constructor | `__init__`, or generated by `@dataclass` |
| `Console.ReadLine()` | `input()` |
| `Console.WriteLine()` | `print()` |
| Repository/database class | `FileDatabase` class |
| JSON serialization | `to_dict()` / `from_dict()` |
| JSON file storage | `json.dump()` and `json.load()` |

## Current OOP Structure

| Class | Responsibility |
| --- | --- |
| `Vehicle` | Holds vehicle data |
| `InspectionReport` | Holds inspection scores and business logic |
| `FileDatabase` | Saves and loads reports from a JSON file |
| `AutoTrustConsoleApp` | Handles the console menu and user input |
